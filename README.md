# 🌍 جولة العالم — لعبة تفاعلية متعددة الأجهزة

لعبة غرفة واحدة: شاشة كبيرة (تلفزيون/بروجكتر) + كل فريق يدخل من جواله.
ثلاث جولات: **علم خاطف** (سرعة الجرس) — **الخريطة الصامتة** (دبوس على خريطة بلا أسماء) — **المزاد** (رهان بالنقاط قبل رؤية السؤال).

## التشغيل في المجلس (نفس شبكة الواي فاي)
1. ثبّت Node.js (الإصدار 18 أو أحدث) على اللابتوب.
2. داخل مجلد المشروع:
   ```
   npm install
   npm start
   ```
3. افتح على اللابتوب الموصول بالشاشة: `http://localhost:3000/host`
4. تظهر على الشاشة QR ورابط مثل `http://192.168.1.20:3000` — الجوالات تمسح الرمز وتدخل اسم الفريق.
   (الفريق الثنائي: جوال واحد يكفي، أو جوالان بنفس الاسم).

> إذا لم تفتح الجوالات الرابط: تأكد أن الجميع على نفس الشبكة، وأن جدار حماية الويندوز يسمح لـ Node بالمنفذ 3000.

## النشر على الإنترنت (للجوالات على بيانات الشبكة)
ارفع المجلد إلى GitHub ثم أنشئ خدمة ويب مجانية على Render أو Railway:
- Build: `npm install` — Start: `npm start`
- أضف متغير البيئة `PUBLIC_URL` بقيمة رابط الخدمة (مثل `https://world-game.onrender.com`) ليظهر QR صحيح.
- اختياري: `HOST_KEY=كلمة_سر` ثم افتح المضيف عبر `/host?key=كلمة_سر` حتى لا يتحكم أحد غيرك باللعبة.

## تعديل الأسئلة — `questions.json`
- **flag**: `{"flag":"jp","answer":"اليابان","options":[...]}` — رمز العلم بحروف ISO صغيرة (ملفات الأعلام في `public/flags/`).
- **map**: دولة `{"text":"أين تقع اليابان؟","country":"JP"}` أو مدينة بإحداثيات `{"text":"...","label":"إسطنبول","lat":41.01,"lon":28.98}`.
- **auction**: `{"category":"جغرافيا","difficulty":"سهل","text":"...","options":[...],"answer":2}` (رقم الإجابة يبدأ من 0).
يمكنك إضافة جولات أو تكرار نوع الجولة أو تغيير ترتيبها.

## ضبط النقاط والأوقات — أعلى `server.js` (كائن `CFG`)
- الأعلام: زمن الجرس 25 ث، زمن الإجابة 8 ث، صحيح +100، خطأ −50.
- الخريطة: 30 ث، 100 نقطة داخل الدولة وتتناقص حتى الصفر عند بُعد 22% من عرض الخريطة.
- المزاد: 20 ث للرهان و20 ث للإجابة، الحد الأدنى 10، ويُسمح بالرهان حتى 100 حتى لو كان الرصيد أقل.
